一个可以装进 Agent 技能目录的「高拟合模考」Skill：先给考试建**命题画像**（官方考纲/大纲/样卷 + 短视频与内容平台的博主观点），再按考点权重、题型矩阵、难度结构组卷，最后自动判分、给采分点、定位薄弱点并排到考试日的日程。

适用于任何考试与比赛：学科期末、考研、CET、职业资格、公考、蓝桥杯、医学词汇大赛、ICT 跨文化能力考试……算法竞赛（蓝桥杯、ICPC/CCPC、Codeforces）走**竞赛模式**。

## 它解决什么
- **不是随机出题**：每道题都能追溯到画像里的考点、维度、难度与来源标签。
- **两套情报源**：官方源定骨架，民间源（抖音/B站/小红书/知乎/公众号/考生实测）调权重、补风向；冲突时官方优先。
- **透明**：卷首标注生成依据与预测性内容占比，博主观点一律标为「预测」，不包装成官方结论。
- **可复算**：分值、题量、难度分布、答案位置全由脚本校验，不靠手算。

## 快速开始
```bash
python scripts/build_exam.py  --spec exam_spec.json --out out/
python scripts/score_exam.py  --spec exam_spec.json --responses responses.json --out out/
```
作答文件：客观题填选项字母，主观题填原文。
```json
{"A1": "B", "A2": "C", "C1": "I would join the celebration and ask about the customs."}
```

## 竞赛模式
竞赛没有标准答案，只有测试点。切到竞赛模式后，产出物变成：

1. 题面：描述 / 输入 / 输出 / 样例 / 约束
2. 每题测试点设计：样例、最小边界、最大规模、随机对拍、卡常构造
3. 题解与正确性论证
4. 赛后复盘：开题顺序、卡题止损、可回收罚时、下场补什么

判分口径：ICPC 按题数与罚时（每次错提交 +20 分钟）；蓝桥杯填空题只看最终结果，编程题按测试点通过。

## 质检门禁
组卷脚本会自动检查六类问题：分值合计、答案合法性、rubric 合计、难度偏离（>10 个百分点）、维度覆盖、答案位置与选项长度（最长项恰为答案超过 60% 即告警）。有 `error` 时不产出卷子，只出质检报告。

- **蓝桥杯软件赛**（`references/profiles/lanqiao.md`）：2010 年首届、第十六届 2025 年；6 大赛项；软件赛 5 个科目；研究生组与大学 A/B/C 组；校赛→省赛→国赛；省赛与决赛均 4 小时；线下赛点、禁网；结果填空题 + 编程大题（标准输入输出、自动评判）。逐题分值官方未公开，标为推定。
- **ICPC / CCPC**（`references/profiles/icpc.md`）：3 人一队、5 小时、8–13 题、全过才 AC、每次错提交罚 20 分钟、排名先题数后罚时，附四档难度带。

新增考试时复制该档案结构，填「事实 / 结构 / 高频考点 / 评分 / 情报现状 / 更新记录」六段；推定内容必须标 `推定`。

## 边界
- 不复刻受版权保护的真题原文或竞赛题库存量，只复刻结构与规律，题目全部原创。
- 不承诺命中率；博主观点标注为预测，保留反押题提示。
- 主观题机器评分只是按采分点关键词的初评，最终以人工复核为准。
