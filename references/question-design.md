# 命题与质检细则

## 一、总则

1. **一题一考点。** 题干只考一个可命名的考点，跨考点联动只出现在"难"档与案例题。
2. **情境优先。** 能用真实场景考的，不要用定义默写。知识类考试至少 60% 的客观题带情境。
3. **答案有据。** 每个正确选项背后要有一条可陈述的依据（文化事实、理论定义、评分口径）。写不出依据的题直接删。
4. **反刻板印象。** 文化类题目不得把某国人群写成同质整体；正确选项应是"识别差异并调整"，而非"照搬某国规矩"。
5. **语言干净。** 题干不含双重否定、不含两个问句；选项语法结构平行。

## 二、客观题

### 题干类型

| 类型 | 形态 | 适用 |
|---|---|---|
| 情境判断 | "You are … What would you most likely do?" | 技能、态度、意识维度 |
| 知识识记 | "Which of the following is …?" | 文化知识维度 |
| 概念辨析 | "What is the main difference between A and B?" | 理论、认知维度 |
| 归因分析 | "The misunderstanding most probably results from …" | 中高档、案例型 |
| 纠错判断 | "Which of the following behaviors is inappropriate?" | 礼仪、禁忌类 |

### 干扰项类型学（至少覆盖 3 类）

1. **文化中心主义**：按本国习惯处理他国情境。
2. **过度概括**：把个别现象说成该文化普遍规律。
3. **张冠李戴**：把 A 国习俗安到 B 国。
4. **绝对化**：always / never / all / must 类表述。
5. **正确但无关**：陈述本身没错，但不回答所问。
6. **反向表述**：把正确做法写成"避免……"造成语义反转。
7. **时间/地域错位**：传统习俗套现代职场、城市习俗套乡村。
8. **貌似礼貌实则冒犯**：看起来体贴，实则触碰禁忌。

### 选项工程检查

- 四项同构：同为动词短语 / 同为名词短语 / 同为完整句。
- 长度差 ≤ 30%，最长项不得恒定是答案。
- 不用"以上都对/以上都不对/无关项"凑数。
- 正确答案位置在整卷内分布均衡（A/B/C/D 各约 25%，允许 ±5%）。
- 错误选项不得语法错误或术语错误，避免"语法排除"。

### 难度判定

| 档 | 信息步数 | 干扰强度 | 是否需要理论 |
|---|---|---|---|
| 易 | 1 步（直接回忆/单一判断） | 弱，仅 1 个明显错误项 | 不需要 |
| 中 | 2 步（先辨析再判断） | 中，2 个合理干扰 | 可选 |
| 难 | ≥3 步，或需跨模块 | 强，3 个高度合理干扰 | 需要 |

## 三、主观题

### 简答题

结构：`情境（2–3 句）+ 一个明确的开放设问 + 3–4 个采分点`。

- 设问用 "What would you do / Why / How would you respond"，不用 "Discuss everything about…"。
- 采分点必须是**可判断的行为或态度**，不是"言之有理即可"。
- 参考答案给出"基本答案 + 加分表述"，并给一句"常见失分"。

### 案例分析题

结构：`材料（150–250 词）+ 2–3 个冲突点 + 三层设问`。

三层设问固定为：① 识别冲突（What is the conflict?）② 理论归因（Why, using at least one concept/theory）③ 提出方案（What would you do, and why is it appropriate?）。

材料写法：
- 用具体人名、地点、时间，不写"某国人"。
- 冲突来自**期待错位**（时间观、直接/间接、面子、权力距离、个人/集体），不来自"某人没礼貌"。
- 埋 1 个"看似无关但关键"的细节（如对方反复确认书面记录 → 低语境/不确定性规避）。
- 不出现真实企业负面信息，公司名用虚构或中性代称。

### 采分点 rubric（写进 spec）

```json
"rubric": [
  {"point": "识别出时间观念差异（monochronic vs polychronic）", "score": 6, "keywords": ["time", "punctual", "schedule", "monochronic", "polychronic"]},
  {"point": "指出未使用面子/间接沟通策略", "score": 6, "keywords": ["face", "indirect", "save face", "direct"]},
  {"point": "给出可执行的调整方案", "score": 8, "keywords": ["reschedule", "confirm in writing", "buffer", "explain"]}
]
```

规则：命中任一关键词记全分；未命中但语义等价由人工复核补分。`score` 合计必须等于该题分值。

### 主观题评分口径

- 按点给分，不按字数给分；堆字数不给分。
- 语言分单列（如 20% 权重）：语法、术语准确、段落层次。
- 反模板：整段套话（"文化没有优劣，我们要尊重差异"）无具体指向的，只给态度分、不给分析分。

## 四、质检清单（与 SKILL.md 六门禁对应）

- [ ] 每题的 `topic` 在画像考点表内，且分值权重与表一致
- [ ] 客观题 `answer` 是选项之一；四个选项互斥且只有一个成立
- [ ] 主观题 `rubric.score` 合计 = 该题分值
- [ ] 全卷分值合计 = 满分；各模块题量与题型矩阵一致
- [ ] 难度分布偏差 ≤ 10 个百分点
- [ ] 各维度（如 CAK 六维）至少各 1 题
- [ ] 答案位置分布均衡，最长选项不是答案的占比 > 60%
- [ ] 案例材料无真实企业/个人负面指向
- [ ] 解析含"依据 / 干扰项分析 / 常见错因"三要素

## 五、常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 伪情境 | 加了人名地名，实际仍是定义题 | 把设问改成"你会怎么做" |
| 送分题 | 三个选项明显荒谬 | 至少两个干扰项要"像对的" |
| 一题多考 | 一道题既考礼仪又考理论 | 拆成两题 |
| 文化刻板 | "德国人都很准时" | 改成"在该情境中，守时是对方的核心期待" |
| 主观题无标准 | "言之有理即可" | 拆 3–4 个采分点，每点可判定 |
| 难度失真 | 全卷都是易题，正确率虚高 | 按表 3 配比，硬题放在后段 |
| 解析空洞 | 只写"故选 B" | 补依据、干扰项错因、易混点 |
| 计量错误 | 分值加起来不等于满分 | 用脚本校验，不手算 |
