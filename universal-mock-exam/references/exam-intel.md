# 考情建模与双源情报

本文件规定 Step 1–3 的执行细节。目标是把"这个考试长什么样"变成可计算、可出题的结构。

## 一、官方源检索矩阵

按顺序检索，先官方后民间。每个源都要记录：URL、发布日期、是"规则"还是"样例"。

| 目标 | 检索式模板 | 要拿到的字段 |
|---|---|---|
| 考试总览 | `<考试全称> 考试介绍 题型 级别 时长 满分` | 时长、满分、档位线、题型清单、语言、机考/纸笔 |
| 考纲/大纲 | `<考试全称> 考试大纲 试卷构成` | 模块划分、题量、单题分、分值合计 |
| 样卷 | `<考试全称> 样题 样卷 例题 解析` | 设问风格、选项风格、案例长度 |
| 真题规律 | `<考试全称> 真题 题型分布 高频考点 分值` | 各模块实际占比、历年变化 |
| 评分标准 | `<考试全称> 评分标准 采分点 阅卷` | 主观题给分口径、步骤分 |
| 级别适配 | `<考试全称> 初级 适合 水平 报考建议` | 难度锚点（对标 CET/雅思/托福等） |
| 当期通知 | `site:<官网域名> <年份> <月份> 报名` | 当期时间、形式变化、新规 |

优先抓官网、考试院/组委会、官方公众号。官网 PDF 用 `web_fetch` 的 snippet 模式定向取"试卷构成/题型/分值"，不要整本下载。

**官方源拿不到逐题分值时的处理**：标注"官方未公开逐题分值"，改用"考生实测反馈 + 第三方备考资料"交叉推定，并在画像里把该结构标为 `推定结构 v0.x`，可配置、可被官方大纲覆盖。

## 二、民间源采集

### 平台与抓取要点

| 平台 | 找什么 | 抓取方式 |
|---|---|---|
| 抖音 / 快手 | 考情分析、押题串讲、真题复盘、避坑、评分细则解读 | browser-use 进站内搜索，按播放/点赞排序，取前 10–15 条，看标题+口播字幕+置顶评论 |
| B站 | 章节考频统计、题型套路、上岸经验、模拟卷测评 | 站内搜索 + 按播放量排序，优先 10 分钟以上讲方法的视频 |
| 小红书 | 备考日程、资料清单、踩坑记录、分数区间自述 | 关键词 + "经验/避坑/复盘"，看正文与高赞评论 |
| 知乎 | 长文方法论、争议题讨论、评分口径质疑 | 按赞同排序，取高赞长答 |
| 微信公众号 | 机构考情发布会、大纲解读、冲刺串讲 | 搜"<考试简称> 考情/冲刺/押题" |
| 贴吧 / 超话 / QQ群公开帖 | 考场实录、题型变化的第一手反馈 | 只看可公开访问内容 |
| 院校/单位通知 | 考点安排、级别建议、官方模拟入口 | 官网检索，权威度高 |

### 抽取字段（只取能影响命题的）

```json
{
  "exam": "ICT 初级",
  "source_type": "official|institution|teacher|blogger|student",
  "platform": "douyin|bilibili|xhs|zhihu|wechat|site",
  "url": "...",
  "date": "YYYY-MM-DD",
  "claims": [
    {"type": "high_freq_topic", "content": "送礼禁忌/名片礼仪每年必考", "confidence": "explicit|implied"},
    {"type": "structure_change", "content": "客观题题量增加，时间更紧", "confidence": "..."},
    {"type": "difficulty_trend", "content": "初级偏基础情境判断", "confidence": "..."},
    {"type": "scoring_change", "content": "主观题按点给分，需覆盖 4 个以上要点", "confidence": "..."},
    {"type": "anti_prediction", "content": "冷门国别文化回潮", "confidence": "..."}
  ]
}
```

`type` 固定枚举：`high_freq_topic`、`new_topic`、`removed_topic`、`structure_change`、`difficulty_trend`、`style_change`、`scoring_change`、`anti_prediction`、`pitfall`。

## 三、可信度分层与加权

| 层级 | 来源 | 权重 |
|---|---|---|
| S | 官方大纲/样卷/考试说明、组委会公开解读 | 40 |
| A | 机构教研团队、多年教龄一线名师、历年命中率可查的头部博主 | 35 |
| B | 普通机构老师、高分考生长文、垂直中小博主 | 20 |
| C | 零散个人感受、无依据押题、评论区碎片 | 5 |

同一 `claim` 的**共识分**：

```
共识分 = Σ(提及该结论的来源权重 × 明确程度系数) / Σ(该维度全部来源权重) × 100
明确程度系数：explicit=1.0，implied=0.6
```

阈值：`≥60` 上调权重（+10%~30%）；`40–59` 设"保底题量"；`<40` 只做拓展题，不进核心权重。S 级结论直接采纳，不参与投票。

## 四、冲突处理

1. 官方有明确说法 → 以官方为准，民间冲突结论记入报告"存在争议"栏。
2. 官方无说法 → 按 S>A>B>C 加权投票；权重相同时取发布时间更近、样本量更大的一方。
3. 仍无法判定 → 两道题各出一题（覆盖两种可能），解析中写明"命题方向存在分歧，建议两种口径都掌握"。

## 六、《考情趋势补充报告》模板

```markdown
# <考试> 考情趋势补充报告（<日期>）

## 数据基础
官方资料 N 份（列出）；民间情报 M 条（平台分布、时间跨度）；有效去重 K 条。

## 一、共识考点 Top 10
| 排名 | 考点 | 共识分 | 来源层级 | 对命题的影响 |

## 二、结构性变化
题量 / 分值 / 模块 / 时长 / 形式（逐条给证据与置信度）

## 三、风格与难度判断
命题话术、材料长度、设问角度、难度走势

## 四、评分口径变化
采分点数量、给分方式、常见扣分点

## 五、反押题预警
被提醒"不要只押热门"的冷门方向

## 六、争议与不确定
结论矛盾处、证据薄弱处、明确不采纳的传言

## 七、置信度声明
本报告为预测性分析，不代表官方命题；预测性内容在本套试卷中的占比为 X%。
```

## 七、情报不足时的降级

触发条件：有效民间情报 < 5 条，或全部集中在单一平台，或全部为 C 级。

降级动作：
1. 不上调任何预测权重，画像完全按官方骨架。
2. 民间源只用于"考生实测反馈"（时间够不够、打字量、机考体验、哪类题最耗时间），写进卷首"作答提示"。
3. 报告中明确写："该考试公开的博主分析稀少，本卷以官方考纲与考生实测为准，未做趋势加权。"
4. 提醒用户：想提高拟合度，可提供本人收集的资料/课程笔记，作为 `用户资料` 源入库。

## 八、合规

- 不抓取、不复述付费课程与付费题库原文；只提炼观点与结构。
- 不指名贬损具体博主；引用观点时标注平台与日期。
- 不把"某博主说必考"写成事实，一律"预测/共识"。
- 官方报名费、考点、时间等信息注明"以官网当期通知为准"。
