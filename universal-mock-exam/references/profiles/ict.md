# ICT 跨文化能力考试档案

> 核验日期：2026-11-22。事实以官网当期通知为准；带 `推定` 字样的内容不是官方公布。

## 一、事实（官方）

| 项 | 内容 |
|---|---|
| 全称 | 全国跨文化能力考试 Intercultural Competence Test（ICT）；同期举办全国跨文化能力竞赛（NICC），二者一体 |
| 研发 | 基于跨文化能力 **CAK 模型**（华中科技大学彭仁忠教授团队），2023 年 5 月首考 |
| 级别 | 初级 / 中级 / 高级，可任选一级 |
| 满分与档位 | 各级满分 **300**，**180 及格**；180–209 合格、210–239 良好、**240 及以上优秀** |
| 时长 | **120 分钟**（9:30–11:30），时间结束自动保存交卷 |
| 形式 | 无纸化**线下机考**，主观题作答内容自动保存 |
| 题型 | **客观题 + 主观题**（主观题为**简答题 + 案例分析题**）；**不含听力、口语** |
| 语言 | 英语 |
| 报名费 | 初级 280 元 |
| 证书 | 通过即得成绩证书（中英对照）；按全国/省内排名另发竞赛奖项 |
| 初级适配水平 | 大学英语一至三级 / CET-4 < 425 / 雅思 < 4 / 托福 < 31（院校通知口径，仅供参考） |
| 官方备考 | 《跨文化能力考试大纲（试行版）》《跨文化能力考试备考指南》《跨文化交际精要》；官网提供机考模拟入口 |
| 奖项比例 | 历年公告不一致（2023 版为前 1%/1–3%/3–5%/5–10%；2026 版为前 3%/3–10%/10–20%/20–35%），**以当期公告为准** |

## 三、试卷结构（推定 v0.1，可按大纲调整）

依据：满分 300；考生实测反馈"选择题题量多、时间紧、几乎没时间回看"；第三方备考资料称"120 分钟 80 道选择题 + 2 道论述题"。官方未公开逐题分值。

| 模块 | 题型 | 题量 | 单题分 | 合计 | 建议用时 |
|---|---|---|---|---|---|
| A 中国文化知识 | 客观 | 20 | 3 | 60 | 15 min |
| B 外国文化知识 | 客观 | 25 | 3 | 75 | 20 min |
| C 交流技能 / 认知技能 / 态度与意识 | 客观 | 25 | 3 | 75 | 20 min |
| D 简答题 | 主观 | 2 | 20 | 40 | 25 min |
| E 案例分析 | 主观 | 1 | 50 | 50 | 35 min |
| 合计 | | 73 | | **300** | 115 min（留 5 min 检查） |

初始难度配比：易 30% / 中 50% / 难 20%。初级以"一步判断 + 基础情境"为主，理论归因只出现在案例题。

## 四、高频考点（初级）

**客观题**：送礼禁忌与包装（菊/紫/刀剪/价签）、名片交换、餐桌与敬酒、左右手与头脚禁忌、时间观与守时、高/低语境、直接与间接、面子与人情、权力距离、个人/集体、非语言（眼神/距离/手势）、宗教禁忌（清真、安息日、斋月）、节日与假期、教育体系（SAT/ACT、A-level、Abitur、高考）、称谓与敬语、小费、商务礼节；中国文化对外表达（节气、书法、中医、和而不同、一带一路）。

**主观题**：态度类（是否参与异国节庆、如何回应冒犯性提问、如何看待文化差异）；案例类（留学生适应、外派管理、小组合作、商务谈判、房东与租客、课堂讨论）。

**理论**：文化冰山、Hofstede 六维、Hall 高/低语境与单向/多向时间、Bennett 跨文化敏感度发展阶段、Berry 文化适应策略、文化冲击四阶段、面子协商理论。

## 五、评分与作答策略

- 客观题按模块编排：中国文化 → 外国文化 → 技能/态度。做每个模块要切换对应维度，不要用同一套思路答到底。
- 简答与案例考态度与综合能力。官方提示的作答关键词：**开放、好奇、平等、尊重、共情、包容**。
- 案例三步：① 找出文化冲突 ② 用概念/理论结合材料归因 ③ 给出可执行方案。分点作答，篇幅不能过短。
- 机考：连打字速度一起练；不要在选择题上死磕。
- 主观题采分点通常 3–5 个，按点给分，堆字数不加分。

## 六、情报现状（2026-11）

- 短视频平台（抖音/B站/快手）公开的 ICT 初级**专门分析稀少**，多为机构转发官方通知、考生短分享。
- 主要民间源：官网"ICT大家说"考生分享、院校教务处报名通知、"跨文化教学与测评"公众号。可信度按 B 级处理，官方考生分享按 A 级处理。
- 结论：**触发降级**——本档案不做趋势加权，民间源只用于作答策略与时间分配建议。
- 想提升拟合度：让用户提供其课程笔记/机构资料，作为"用户资料"源入库。
